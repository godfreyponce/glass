# Glass: Portfolio Dashboard

A self-hosted portfolio dashboard built with Next.js 16 and deployed on Vercel,
where markdown files with a locked Zod frontmatter schema are the source of
truth. It features passphrase-gated inline editing and a Quick add flow that
spawns local Claude Code to write new project cards from plain-language
descriptions. Phase 1 is shipped, live, and stable; Phase 2 (real auth,
delete-via-UI, and publishing the migration writeup) is planned. This is the
dashboard itself, tracked as a project within itself.
